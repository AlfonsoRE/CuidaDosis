# ADR-001: Stack tecnológico: Kotlin + PHP + MariaDB (gratuito) frente a nube administrada de pago

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
El proyecto es académico, sin presupuesto. Se necesita cubrir RF-01..RF-18 y RNF-01..08 con herramientas que el equipo ya domina. Se comparó con una alternativa de nube (Firebase: Auth, Firestore, Functions, FCM) en plan Blaze.

## Decisión
Se usa app Android nativa (Kotlin + Compose), API REST en PHP 8 sobre Apache y MariaDB, ejecutables sin costo (XAMPP).

## Alternativas consideradas
A) Firebase (Spark/Blaze): Cloud Functions exige plan Blaze con tarjeta y facturación por uso; Spark no permite nuevos despliegues de Functions. B) Backend Node/Java en VPS de pago. C) Stack propio (elegido).

## Fundamento
Costo cero de licencias y despliegue reproducible en el equipo del curso; el equipo controla datos y esquema (protección de datos). Firebase ofrece FCM sin costo y mejor escalabilidad, pero introduce dependencia de proveedor y cobro por uso.

## Consecuencias
Positivas: sin costo, reproducible, datos bajo control. Negativas: sin push (RF-17 queda como Futuro), el equipo administra servidor, respaldo y TLS; escalabilidad limitada al hardware disponible. Si el proyecto se publicara, habría que cotizar hosting y la cuota única de Google Play (US$25).
