# ADR-004: Vínculo con aceptación explícita del paciente y control de intentos

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
Un código adivinado no debe dar acceso al cuidador sin consentimiento (G-01, G-02, G-05).

## Decisión
El código vive 10 min; al introducirlo, el vínculo pasa a awaiting_acceptance y solo el paciente lo activa. Tras 5 fallos en 10 min la API responde 429 (tabla link_attempts).

## Alternativas consideradas
Activación directa sin aceptación; códigos de 48 h.

## Fundamento
Reduce el riesgo de acceso no autorizado a datos de salud.

## Consecuencias
Un paso más de interacción para el paciente; nueva tabla y estado.
