# ADR-009: Tokens de sesión con hash SHA-256 y almacenamiento cifrado en el teléfono

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
RNF de seguridad y protección de datos.

## Decisión
El servidor guarda solo el hash del token; la app guarda la sesión cifrada (AES-GCM, Keystore).

## Alternativas consideradas
JWT sin estado; token en claro.

## Fundamento
Un volcado de BD no expone sesiones.

## Consecuencias
Hay que consultar BD en cada petición.
