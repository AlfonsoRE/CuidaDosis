# ADR-006: Etiqueta «Confirmada por el paciente» y confirmación con un toque

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
Observación del doctor: el sistema no verifica ingesta; RF-07 pide un toque sin diálogo adicional.

## Decisión
La acción «Tomado» registra «Confirmada por el paciente» sin diálogo; el sistema no afirma que la dosis se ingirió.

## Alternativas consideradas
Etiqueta «Tomada»; diálogo de confirmación.

## Fundamento
Honestidad sobre el alcance y menor fricción para adultos mayores.

## Consecuencias
Un toque accidental no tiene deshacer salvo que se defina (a verificar en P4).
