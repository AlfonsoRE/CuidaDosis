# ADR-003: Confirmación offline-first con cola local e identificador UUID

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
RF-13: el paciente debe confirmar sin red y sincronizar sin duplicados (G-03).

## Decisión
La app guarda localmente cada confirmación con un UUID generado en el cliente y la envía en lote; el servidor define client_uuid como UNIQUE y responde de forma idempotente.

## Alternativas consideradas
Exigir red para confirmar; sincronización por marca de tiempo.

## Fundamento
El UUID hace la operación idempotente ante reintentos; sigue el patrón offline-first de la guía de Android.

## Consecuencias
Más código en el cliente (almacén local, reintentos); la fuente de verdad se reparte entre teléfono y servidor hasta sincronizar.
