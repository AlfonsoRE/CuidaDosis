# ADR-010: Autorización del paciente para mostrar la dosis al cuidador (G-07)

**Estado:** Aceptada (diseño objetivo P2 v1.1)  
**Fecha:** 2026-11-28

## Contexto
RF-10: la dosis se oculta salvo autorización.

## Decisión
Campo links.share_dose TINYINT(1) DEFAULT 0; diferible a fases posteriores.

## Alternativas consideradas
Mostrar siempre la dosis al cuidador.

## Fundamento
Minimiza datos compartidos.

## Consecuencias
Si se difiere, la API no debe enviar la dosis al cuidador por defecto.
