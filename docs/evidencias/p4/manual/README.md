# Evidencia de pruebas manuales (equipo)

Aquí va el Complemento manual ya lleno, con fecha en el nombre (por ejemplo `Complemento_lleno_2026-11-23.docx`).
Las fotos o capturas de apoyo van en `capturas/`, sin cuentas reales ni la URL privada del servidor.
No se sobrescriben archivos llenos: las correcciones se registran como incidencias.
